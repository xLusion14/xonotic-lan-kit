XONOTIC WORK LAN KIT
====================
The game is built into each setup file. Nothing else to download.

JUST WANT TO PLAY?  Use ONLY:  Xonotic-Player-Setup.exe
-------------------------------------------------------
1. Double-click Xonotic-Player-Setup.exe. It takes under a minute.
2. Double-click "Play Xonotic" on your desktop.
3. The game opens on "Games on your network". Click "Work LAN", then "Join!".
   Set your name under "Your player". The gear icon opens Settings;
   click Close or anywhere outside the window to go back.
   Not listed? Click Refresh, or type the address shown in the host's
   Xonotic Server window into Address and click Join!
Xbox controller: plug it in before starting the game. Triggers fire,
A jumps, B crouches, bumpers switch weapons, Start opens the menu.

Players: do NOT run the Server Setup. Only the host needs it.


HOSTING (ONE person only):  Xonotic-Server-Setup-HOST-ONLY.exe
---------------------------------------------------------------
1. Double-click Xonotic-Server-Setup-HOST-ONLY.exe and type Y to confirm.
   It installs the game and opens the Xonotic Server window, which
   starts the server.
2. If Windows Firewall asks about xonotic-dedicated, click Allow.
3. Keep the Xonotic Server window open while people play.
4. In that window: change game mode and map (Change Now), restart the
   match, change limits and bots (Save Settings), start/stop/restart
   the server, and see who's playing.
5. Next time, use the "Xonotic Server" shortcut on the desktop.
6. You can play on the host laptop too: use "Play Xonotic".


GOOD TO KNOW
------------
- The game installs to C:\Games\Xonotic
- The server list only shows games on your own network
- The game runs fullscreen at the screen's own resolution
- Weak laptop stuttering? Gear icon > Effects > Low
- Text too big or small? Gear icon > Video > Font/UI size
- "Windows protected your PC"? Click More info > Run anyway
- Uninstall: delete C:\Games\Xonotic and the desktop shortcuts
